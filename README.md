# Распознавание изолированных жестов русского жестового языка

Модель распознавания изолированных жестов русского жестового языка (РЖЯ) на основе скелетных координат кистей рук.

## Описание

Данная модель предназначена для распознавания изолированных жестов русского жестового языка. Входные данные — скелетные координаты кистей рук, извлечённые с помощью MediaPipe. Модель работает с последовательностями скелетных данных и классифицирует жест по 1000 классам.
